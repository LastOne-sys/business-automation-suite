# Четыре проекта: запуск и демонстрация

Это четыре работающих локальных приложения, а не четыре макета. У каждого отдельная база, пароль, интерфейс и архив для передачи. Внешние сервисы и публичный хостинг не подключены.

## Быстро открыть здесь

После запуска демонстраций:

- QuoteDesk: http://127.0.0.1:8111
- InvoiceDesk: http://127.0.0.1:8112
- SupportDesk: http://127.0.0.1:8113 ; клиентская форма /public
- BookDesk: http://127.0.0.1:8114 ; запись клиентов /public

Пароль каждого приложения — во второй строке его файла `data/<имя>-demo/FIRST-LOGIN.txt`. Это локальные секреты: не публикуйте их вместе со скриншотами. После смены пароля исходный файл удаляется.

## 1. QuoteDesk: предложение клиенту

Откройте «Каталог товаров» и посмотрите цены. На рабочем столе создайте предложение: клиент, email, строки `LAMP-01,2` и `WIRE-10,1`. Укажите скидку. Приложение рассчитает сумму; подтвердите документ и выберите «Печать / PDF». Добавление неизвестного артикула заблокирует подтверждение. После обновления каталога нужно создать исправленное предложение, а старое можно убрать в архив.

## 2. InvoiceDesk: контроль входящих счетов

Добавьте текст счёта или загрузите PDF с текстовым слоем. Сверьте оригинал и поля. В демонстрации один счёт содержит намеренно неверный итог: 100 + 20 ≠ 130. Исправьте итог на 120, сохраните, подтвердите. После этого он появится в CSV-экспорте. Повторная загрузка того же текста не создаст второй документ. Отметка «Оплачено» — только учёт статуса, она не переводит деньги.

## 3. SupportDesk: помощь клиентам

В «Базе знаний» задаются проверенные тексты и ключевые слова. На клиентской странице задайте вопрос «Какие сроки доставки заказа?» и получите текст с указанием статьи. Вопрос о банковских реквизитах попадёт оператору, без выдуманного ответа. Оператор может написать ответ, скачать письмо .eml и отправить его своей почтой. Поиск не является генеративным AI; при продаже это следует назвать помощником по базе знаний.

## 4. BookDesk: запись на встречу

Установите часовой пояс в настройках, затем откройте клиентскую страницу. Выберите будний день, услугу, свободное время и контактные данные. Сохраните календарный файл и личную ссылку отмены. Во второй вкладке тот же слот станет недоступен. Администратор может отменить запись. Раздел напоминаний готовит письма для записей в ближайшие 24 часа, но не отправляет их.

## Установка на другой компьютер

Распакуйте нужный архив из `dist`. Установите Python 3.11+, затем запустите `install.ps1` (команда приведена в README) и `START.cmd`. `DEMO.cmd` создаёт отдельные вымышленные данные; рабочие данные не подменяются демонстрацией. Окно запуска нужно держать открытым. Для остановки — Ctrl+C в этом окне.
